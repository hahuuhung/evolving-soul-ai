# Roadmap

- Capsule Format 1.0, encrypted proposal queue, local review sidecar
- passkey ceremonies and scoped Open WebUI integration
- content-blind coordinator domain model and PostgreSQL adapter
- conformance tests and synthetic demo

## Beta gates

- public threat-model review
- recovery drills on Linux, Windows, and macOS
- independent cryptographic design review
- Open WebUI E2E on 0.11.2 and the two latest minor releases

## 3.0.0 gates

- independent external audit completed
- no unresolved Critical or High finding
- coordinated disclosure process exercised
- compatibility suite frozen for Capsule Format 1.0

MCP, multi-tenant sidecars, and model-callable write tools are intentionally deferred.
