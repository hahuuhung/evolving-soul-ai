# Changelog

All notable changes use Keep a Changelog conventions. The project uses semantic versioning for the
Python package; the `.soul` format has an independent version.

## 3.0.0a1 — unreleased

- Reset the project around local-first AI-memory continuity.
- Added Capsule Format 1.0 with AES-256-GCM compartments, HKDF separation, Ed25519 signatures,
  Argon2id export wrapping, ZIP safety limits, and typed legacy rejection.
- Added encrypted pending proposals, explicit owner consent, transient BM25 retrieval, passkey
  adapters, a local FastAPI control plane, coordinator state machine, and Open WebUI Functions.
- Excluded behavioural scoring, password-habit learning, face recognition, and V2 migration from
  the distribution.
- Replaced the custom attribution license with Apache-2.0.
